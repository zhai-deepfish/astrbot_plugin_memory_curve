# 潮汐记忆 · astrbot_plugin_memory_curve

> 对话越聊越长，记忆越用越准。

给 AstrBot 做一个分层记忆：最近的对话留在窗口里，旧事压成摘要和事实，真要翻旧账时再检索回来。聊天窗口动辄几十万 token 的问题，能压到几千。

## 它是怎么想的

| 层 | 存什么 | 默认寿命 | 怎么来的 |
|---|---|---|---|
| **L1 最近对话** | 最近 10 轮原文 | 滚动覆盖 | 每轮直接落盘 |
| **L2 短期摘要** | 一句话概括 + 关键词 + 分数 | 24 小时 | 每轮调一次便宜模型判重要性并摘要 |
| **L3 长期事实** | 身份、偏好、约定、明确要求记住的事 | 30 天（被提到就续期） | 分数 ≥4 的 L2，每天提升一次 |
| **L4 全量存档** | 所有对话原文，按天 jsonl | 永久 | 每轮追加，供检索 |

每轮处理顺序：维护（去重、过期、跨天提升）→ 判分 → 检索 → 拼进 system_prompt → 放行给主模型。

主模型只负责说话，判定和摘要交给便宜的 flash 级模型，钱花得明白。

## 装法

拿到 `astrbot_plugin_memory_curve-1.0.3.zip`（顶层就是插件文件夹本身），二选一：

- **WebUI**：插件管理页找「上传插件 / 安装插件」，选 zip 上传，然后重载插件
- **手动**：解压到 `AstrBot/data/plugins/` 下，确认路径是 `data/plugins/astrbot_plugin_memory_curve/main.py`，只隔一层目录

重载插件即可，没有额外依赖。图文步骤见包内 `安装说明.md`。

## 配置

| 项 | 默认 | 说明 |
|---|---|---|
| `enabled` | `true` | 总开关 |
| `data_dir` | 空 | 记忆数据目录，留空用 `data/plugin_data/astrbot_plugin_memory_curve` |
| `judge_provider_id` | 空 | 判分模型 ID，留空则用当前会话主模型 |
| `l1_max_turns` | `10` | L1 保留最近几轮 |
| `l2_expire_hours` | `24` | L2 摘要保留小时数 |
| `l3_expire_days` | `30` | L3 事实保留天数（未被提及则下架） |
| `l3_max_items` | `20` | 注入的 L3 上限 |
| `l2_max_items` | `10` | 注入的 L2 上限 |
| `retrieve_limit` | `3` | 每轮最多召回几条旧片段 |
| `enable_judge` | `true` | 关掉就只按规则存，不调模型 |

判分模型建议挑便宜的（DeepSeek Flash、GLM Flash 这类都行），它每轮都要跑一次。

## 指令

管理员指令，别人动不了：

```
记忆              列出 L3 / L2，并标记出一看就该清理的一次性任务
记忆 加 老大爱吃白米饭      手动塞一条长期事实
记忆 改 3 老大生日是三月十二  改第 3 条
记忆 删 3,5        删第 3 和第 5 条（L2 里同一条也一起清）
记忆 清理           清掉混进长期记忆的一次性任务
```

改数据前会自动备份成 `l3.bak-时间戳.json`，最近留 5 份。

## 几个刻意的设计

- **只留一条**：L2 和 L3 都按归一化文本判重，同一件事反复提不会堆成十份白烧 token。
- **重载不重复提升**：「今天已经提升过」写进 `state.json`，重载插件不会把 L2 再刷一遍进 L3。
- **一次性任务不入长期**：「帮我改改」「重载一下」这种办完就没的事，只在 L2 待一天。
- **它自己的承诺也记**：回复里带「我」和「我会/我帮你/提醒你」的句子会被记成「我答应过：…」，第二天不至于失忆。
- **动上下文之前先看有没有货**：L1 为空时不去碰平台自带的历史，免得把别人的上下文清空。

## 已知的毛边

- 一次性任务的判断是按关键词（检查/改/重载/看看…）来的，不算聪明。有正经事实带了这些字，可能被挡在 L3 外，只在 L2 待一天。碰上用 `记忆 加` 手动补。
- 检索是关键词匹配，不是向量检索。中文里换个说法就搜不到，这是刻意的取舍：零依赖、零额外费用，代价是召回率一般。
- 只处理文字，图片、语音不进记忆。

## 数据都在哪儿

```
<data_dir>/<会话 ID>/
├── l1.json         最近对话
├── l2.json         短期摘要
├── l3.json         长期事实
├── state.json      上次提升日期
├── l1.bak-*.json   改动前的备份
└── archive/2026-10-25.jsonl   全量存档
```

⚠️ **这些文件里是真实对话原文和会话 ID，不要提交到公开仓库。** 仓库自带的 `.gitignore` 已经挡住了。
